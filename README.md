# Street Symphony Collective

STREET SYMPHONY — COMPLETE LOVABLE BUILD PROMPT

Build a complete, responsive web platform called Street Symphony.

Street Symphony is a digital platform for discovering, documenting, showcasing, and booking India's street artists and folk artists.

The platform connects artists with people and organisations looking to experience, support, and book authentic cultural performances.

The website should combine:

Contemporary Indian editorial design + cultural archive + artist marketplace + storytelling platform.

This should NOT look like a generic SaaS product, generic event-booking website, or charity website.

It should feel like a beautifully designed independent cultural publication that also happens to have powerful discovery and booking functionality.

The platform should present them with respect, personality, and agency.

Move the entire visual identity toward a warm red, rust, terracotta, ivory, and cocoa palette.

46. FINAL ART DIRECTION

The reference image uses a playful yellow/green palette.

For Street Symphony, reinterpret that visual language through:

Warm Ivory + Rust + Terracotta + Cocoa + Dusty Rose + Muted Sage.

Use the same spirit of:

Bold typography

Botanical elements

Cultural imagery

Editorial collage

Layered composition

but make the final result:

quieter, more sophisticated, more spacious, more editorial, and more premium.

The design should look excellent in a museum, cultural institution, independent magazine, university, festival, or premium event organisation context.

The website should feel like a brand, not a template.

47. PRIORITY ORDER

When making design decisions, prioritise in this order:

Artist dignity and storytelling

Artist discovery

Booking usability

Strong visual identity

Photography

Typography

Accessibility

Performance

Decorative elements

Do not sacrifice usability for visual experimentation.

The final website should be beautiful enough to make someone stop scrolling, but intuitive enough that they can find and book an artist within minutes.
